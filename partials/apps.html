Applications and Pipelines

LittleVet Web Application

  • Developed using HTML, CSS, Python, and Django framework
  • Created a comprehensive Django web application for veterinary clinic management, enabling administration of pet owners, patients (pets), and appointments

DESeq2 Differential Expression Analysis Tool

  • Developed using Shiny and RStudio
  • Accepts two input files (metadata and feature/gene read counts) to calculate differential expression between groups and generate volcano plots in SVG format
  • Provides downloadable correlation plots in SVG format for publication-ready visualizations

Pearson and Spearman Correlation Analysis Tool

  • Developed using Shiny and RStudio
  • Accepts tabular data as input and calculates correlation coefficients and p-values using either Pearson or Spearman correlation methods
  • Generates downloadable correlation plots in SVG format for research publications

Nextflow Pipeline for 16S rRNA Profiling Analysis

  • Developed using Nextflow workflow management system
  • Processes raw 16S Illumina paired-end sequencing data through quality control, OTU clustering, taxonomic assignment, visualization, and alpha/beta diversity analysis
